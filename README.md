# Тоннаж по сменам

Страница считает, сколько и каких позиций (в штуках, килограммах и тоннах) приготовила дневная и ночная смена пекарни. Считает по OLAP-выгрузке из iiko за любой период.

**Открыть:** https://annmalikovski.github.io/shift-tonnage/

## Как пользоваться

1. В iiko выгрузите OLAP-отчёт по пресету «Для тоннажа по сменам» в Excel. Колонки: учетный день, время открытия, планируемое время доставки, категория блюда, номер доставки, блюдо, размер блюда, количество блюд.
2. Перетащите файл на страницу.
3. Проверьте блок «Не распознано», если он появился, и нажмите «Скачать Excel».

Файл с продажами читается только в браузере и никуда не загружается: ни на GitHub, ни куда-либо ещё.

## Правило смен

- **Дневная смена:** всё, что принято в тот же учетный день, при любом времени доставки. Плюс заказы, принятые раньше, с началом доставки с 14:00.
- **Ночная смена:** заказы, принятые раньше учетного дня, с началом доставки до 13:00 включительно. Учитывается только час начала доставки.

## Справочник — `spravochnik.json`

В справочнике три списка:

- `positions` — позиции с весом одной штуки, группой и блоком («Из-под ножа» или «Прочие»);
- `aliases` — названия из отчёта, которые не совпадают с позицией. Например, модификаторы наборов: «Американский» → «Американский Баноффи пай 24 см»;
- `exclusions` — что не считаем: торты, чизкейки, напитки, наборы с пустой ТТК, доставка.

Позиция находится сама, если название из отчёта вместе с размером совпадает с названием позиции. Регистр, ё/е, кавычки и латинские буквы-двойники не важны.

**Как править.** Проще всего прямо на странице, в разделе «Справочник» или в блоке «Не распознано». Затем нажмите «Сохранить в справочник». Правка сохранится в этот репозиторий отдельным коммитом, а вся история изменений видна во вкладке *Commits*. Другие увидят правку, как только обновят страницу.

Для сохранения нужен токен GitHub. Его достаточно создать один раз на каждый браузер:

1. Откройте GitHub: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. В *Repository access* выберите **Only select repositories** → `shift-tonnage`.
3. В *Permissions → Repository permissions → Contents* выберите **Read and write**.
4. Скопируйте токен и вставьте его на странице: кнопка «Доступ на сохранение».

Токен даёт право менять только этот репозиторий и хранится только в том браузере, где его ввели. Когда истечёт срок, создайте новый.
