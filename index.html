Справочник

Откуда берётся вес и как названия из отчёта превращаются в позиции. Хранится в репозитории на GitHub, файл spravochnik.json. Правки сразу пересчитывают загруженный файл; чтобы они попали в общий справочник, их нужно сохранить.

Доступ на сохранение правок

  1. Откройте на GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → этот репозиторий. Permissions → Repository permissions → Contents: Read and write.
  3. Скопируйте токен и вставьте сюда. Он сохранится только в этом браузере.
